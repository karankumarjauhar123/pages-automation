# Influencer Faces

Upload the face images of the influencers you want to swap onto the reels here.

## How to Upload via GitHub Web Interface:
1. Navigate to this folder in your repository on GitHub.
2. Click **Add file** -> **Upload files** at the top right.
3. Drag and drop your influencer face image (e.g., `karan.jpg`, `anushka.png`).
4. Click **Commit changes...** at the bottom to save the image to the repository.

## Recommendations:
* Use high-quality, clear, front-facing close-up shots of the face.
* Avoid photos with hats, sunglasses, heavy angles, or hands covering the face.
* Keep the image name simple (e.g., `karan.jpg`) because you will type this name in the GitHub Actions input field.
